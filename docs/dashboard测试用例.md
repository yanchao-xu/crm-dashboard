# CRM Dashboard 测试用例

## 一、页面加载与状态

| 编号 | 用例名称     | 前置条件         | 操作步骤            | 预期结果                                             |
| :--- | :----------- | :--------------- | :------------------ | :--------------------------------------------------- |
| 1.1  | 加载中状态   | API 请求未返回   | 打开 Dashboard 页面 | 显示加载动画（旋转图标）和"加载数据中..."文案        |
| 1.2  | 加载失败状态 | API 返回错误     | 打开 Dashboard 页面 | 显示"数据加载失败"及具体错误信息                     |
| 1.3  | 空数据状态   | API 返回空数组   | 打开 Dashboard 页面 | 显示"暂无数据"                                       |
| 1.4  | 正常加载     | API 正常返回数据 | 打开 Dashboard 页面 | 三个图表（健康度、漏斗、停滞）均正常渲染，筛选器可用 |

## 二、组织筛选器 (OrgFilter)

| 编号 | 用例名称               | 前置条件                     | 操作步骤                         | 预期结果                                                        |
| :--- | :--------------------- | :--------------------------- | :------------------------------- | :-------------------------------------------------------------- |
| 2.1  | 默认状态               | 页面正常加载                 | 观察组织筛选器                   | 显示"全部组织"，无选中状态                                      |
| 2.2  | 展开组织树             | 页面正常加载                 | 点击组织筛选器按钮               | 弹出组织树，第一层默认展开，显示公司/区域/团队/个人层级         |
| 2.3  | 选中组织节点           | 组织树已展开                 | 点击某个团队节点                 | 筛选器显示该团队名称，按钮高亮，显示节点类型标签（如"团队"）    |
| 2.4  | 组织筛选生效           | 选中某个团队                 | 观察图表                             | 商机健康度、漏斗和停滞图仅包含该团队下人员的 deal.owner 数据；回款健康度和回款合同仅包含该团队下人员的应收 paymentOwner 数据 |
| 2.5  | 选中个人节点           | 组织树已展开                 | 点击某个 person 节点                 | 商机类图表匹配该人员的 deal.owner；回款模块匹配该人员的应收 paymentOwner（按用户 ID/email，不按姓名）                         |
| 2.6  | 清除组织筛选           | 已选中某组织                 | 点击筛选器旁的 X 按钮            | 恢复"全部组织"，图表恢复全量数据                                |
| 2.7  | 选择"全部组织"         | 已选中某组织                 | 打开下拉，点击顶部"全部组织"选项 | 同 2.6                                                          |
| 2.8  | 健康度 target 跟随组织 | 选中某组织节点（含月度配额） | 观察健康度图表 target 线         | target 值取自该组织节点的月度字段（janJanuary, febFebruary 等） |
| 2.9  | 未选组织时 target      | 未选中任何组织               | 观察健康度图表 target 线         | target 值取自根组织节点的月度字段                               |

## 三、产品线筛选器 (ProductTeamFilter)

| 编号 | 用例名称                     | 前置条件         | 操作步骤                     | 预期结果                                                                                                                                                |
| :--- | :--------------------------- | :--------------- | :--------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 3.1  | 默认状态                     | 页面正常加载     | 观察产品线筛选器             | 显示"产品线"文案（Package 图标），无选中标记                                                                                                            |
| 3.2  | 选中单个产品线               | 点击产品线筛选器 | 勾选一个产品线               | 按钮显示选中数量 badge (1)，按钮高亮（border-primary bg-primary/10）；图表仅显示 deal.productLine 包含该产品线 ID 的商机                                |
| 3.3  | 选中多个产品线               | 点击产品线筛选器 | 勾选多个产品线               | badge 显示对应数量，图表显示 deal.productLine 包含任一选中产品线 ID 的商机（OR 逻辑）                                                                   |
| 3.4  | 取消选中                     | 已选中产品线     | 取消勾选所有产品线           | 恢复全量数据，badge 消失，按钮恢复默认样式                                                                                                              |
| 3.5  | 清除全部按钮                 | 已选中产品线     | 点击下拉内"清除全部"         | 所有选中项取消，恢复全量数据                                                                                                                            |
| 3.6  | 组织+产品线联合筛选          | 已选中组织       | 再选中产品线                 | 图表数据为两个筛选条件的交集（先按组织过滤 owner，再按产品线过滤 productLine）                                                                          |
| 3.7  | 筛选"无产品线"商机           | 点击产品线筛选器 | 勾选"无产品线"选项           | 图表仅显示 deal.productLine 为空数组或 undefined 的商机                                                                                                 |
| 3.8  | "无产品线"+产品线联合筛选    | 点击产品线筛选器 | 同时勾选"无产品线"和某产品线 | 图表显示 productLine 为空的商机 + productLine 包含该产品线 ID 的商机（OR 逻辑取并集）                                                                   |
| 3.9  | 仅选产品线时排除无产品线商机 | 选中产品线       | 观察筛选结果                 | deal.productLine 为空数组或 undefined 的商机不会被包含在筛选结果中（需勾选"无产品线"才能看到）                                                          |
| 3.10 | "无产品线"选项位置           | 点击产品线筛选器 | 观察下拉选项列表             | "无产品线"选项位于列表第一项，在所有具体产品线之前                                                                                                      |
| 3.11 | 产品线数据来源               | 页面正常加载     | 观察产品线选项               | 选项来自数据字典 API（parentHandle="productSeries"），名称根据当前语言使用 i18n 字段（codeName_i18n_zh-CN / codeName_i18n_en-US / codeName_i18n_ja-JP） |
| 3.12 | 筛选条件标签显示             | 选中产品线       | 观察图表卡片顶部标签         | 显示"产品线: [产品线名称]"标签，可点 X 移除                                                                                                             |

## 四、金额模式筛选器 (AmountModeFilter)

| 编号 | 用例名称                       | 前置条件     | 操作步骤               | 预期结果                                                                                                  |
| :--- | :----------------------------- | :----------- | :--------------------- | :-------------------------------------------------------------------------------------------------------- |
| 4.1  | 默认状态                       | 页面正常加载 | 观察金额模式筛选器     | 默认选中"预期金额"（expectedAmount），显示美元图标                                                     |
| 4.2  | 切换到商业金额模式             | 默认模式     | 选择"商业金额"         | 商机健康度、漏斗和停滞图的金额计算切换为使用 deal.businessAmount 字段；回款模块数据不变                   |
| 4.3  | 切换回预期金额模式             | 商业金额模式 | 选择"预期金额"         | 商机健康度、漏斗和停滞图恢复使用 deal.value（expectedTransactionAmount）字段；回款模块数据不变           |
| 4.4  | 金额模式影响商机健康度图表     | 切换金额模式 | 观察商机健康度图表柱子 | 各月各阶段的堆叠金额按当前金额模式对应字段累加                                                           |
| 4.5  | 金额模式影响漏斗图             | 切换金额模式 | 观察漏斗图各阶段金额   | 各阶段 value 按当前金额模式对应字段累加                                                                  |
| 4.6  | 金额模式影响停滞图             | 切换金额模式 | 观察停滞图金额数据     | 各活跃度分类的金额按当前金额模式对应字段累加                                                             |
| 4.7  | 金额模式不影响回款模块         | 切换任意金额模式 | 观察回款健康度和月回款合同 | 固定使用应收计划 plannedAmount、actualAmount 和合同展示字段，不使用商机金额模式                        |

| :--- | :--------------------- | :--------------------------- | :------------------------ | :---------------------------------------------------------------------------- |
| 5.1  | 默认状态               | 页面正常加载                 | 观察周期筛选器            | 默认选中"按月"模式，显示日历图标                                              |
| 5.2  | 切换到按季度模式       | 默认按月模式                 | 选择"按季度"              | 健康度图表 X 轴切换为 Q1-Q4 显示，每个季度柱子为该季度 3 个月数据的聚合       |
| 5.3  | 季度模式下 target 聚合 | 按季度模式                   | 观察健康度图表 target 线  | 每个季度的 target 值为该季度 3 个月 target 之和                               |
| 5.4  | 季度模式下点击柱子     | 按季度模式                   | 点击某季度（如 Q1）的柱子 | 漏斗图和停滞图数据按该季度包含的月份过滤（如 Q1 对应 Jan/Feb/Mar）            |

## 六、财年支持

| 编号 | 用例名称               | 前置条件                                         | 操作步骤                 | 预期结果                                                        |
| :--- | :--------------------- | :----------------------------------------------- | :----------------------- | :-------------------------------------------------------------- |
| 6.1  | 自然年月份顺序（默认） | 组织节点无财年配置                               | 观察健康度图表 X 轴      | 显示 Jan-Dec 12 个月                                            |
| 6.2  | 财年起始日期配置       | 组织节点 theStartDateOfTheFiscalYear 为 4 月     | 观察健康度图表 X 轴      | 显示 Apr, May, Jun, Jul, Aug, Sep, Oct, Nov, Dec, Jan, Feb, Mar |
| 6.3  | 仅有财年结束日期       | 组织节点仅配置 theEndDateOfTheFiscalYear 为 3 月 | 观察健康度图表 X 轴      | 结束月往前推 12 个月，显示 Apr-Mar                              |
| 6.4  | 财年月份影响统计卡片   | 财年从 Apr 开始                                  | 观察健康度"当前"统计卡片 | 累计值从 Apr 开始到当前自然月（含），而非从 Jan 开始            |
| 6.5  | 财年月份影响季度划分   | 财年从 Apr 开始，按季度模式                      | 观察季度标签             | Q1=Apr/May/Jun, Q2=Jul/Aug/Sep, Q3=Oct/Nov/Dec, Q4=Jan/Feb/Mar  |
| 6.6  | 跨年财年数据精确匹配   | 财年为 2026-04 ~ 2027-03，商机包含 2026-03 和 2027-03 的数据 | 观察 Mar 柱子数据 | Mar 柱子仅包含 2027-03 的数据，2026-03 的数据不会错误落入该柱子（按 yearMonth "2027-03" 精确匹配） |
| 6.7  | 跨年财年 API 请求范围  | 组织节点财年为 2026-04-01 ~ 2027-03-31           | 观察网络请求             | 商机 API 的 dateFrom="2026-04-01"、dateTo="2027-03-31"，而非当前自然年 01-01~12-31 |
| 6.8  | 数据请求依赖关系         | 页面加载 | 观察请求顺序 | 商机链路保持“组织树→商机→合同→应收计划”；回款链路独立为“组织树/财年→按 plannedDate 查询应收计划→按 parentDataId 反查合同” |
| 6.9  | 无财年配置时 fallback  | 组织节点无 theStartDateOfTheFiscalYear 和 theEndDateOfTheFiscalYear | 观察商机与回款 API 请求 | dateFrom 和 dateTo 使用选中年份自然年（如 "2026-01-01" ~ "2026-12-31"） |
| 6.10 | 跨年财年回款健康度匹配 | 财年为 2026-04 ~ 2027-03，应收计划有 2026-03、2026-04 和 2027-03 的 plannedDate | 观察回款健康度 | 仅查询并统计 plannedDate 在 2026-04-01~2027-03-31 的应收；Mar 仅统计 plannedYearMonth="2027-03"，不包含 2026-03，也不将其作为期初逾期滚入 |
| 6.11 | 跨年财年点击柱子联动   | 财年为 2026-04 ~ 2027-03，按月模式               | 点击 Mar 柱子            | 商机列表仅显示 createdYearMonth="2027-03" 的商机，漏斗和停滞图同步按 yearMonth 过滤 |
| 6.12 | 虚拟根节点财年取值     | 组织树有多个根节点（构建虚拟根）                 | 观察商机 API 请求        | 从虚拟根的第一个子节点获取财年信息，正确确定 dateFrom/dateTo |

## 七、健康度图表 (HealthChart)

| 编号 | 用例名称                    | 前置条件              | 操作步骤                  | 预期结果                                                                                     |
| :--- | :-------------------------- | :-------------------- | :------------------------ | :------------------------------------------------------------------------------------------- |
| 7.1  | 堆叠柱状图渲染              | 有商机数据            | 观察健康度图表            | X 轴显示财年月份（默认 Jan-Dec），每个月的柱子按阶段（来自 opportunityStages）堆叠，颜色不同 |
| 7.2  | Target 虚线                 | 有组织数据            | 观察健康度图表            | 显示虚线折线表示 target，值来自组织节点的月度配额字段                                        |
| 7.3  | 统计卡片 - 当前值           | 有数据                | 观察"当前"统计卡片        | 按月模式：从财年第一个月到当前自然月（含）的所有阶段金额累计总和；按季度模式：从 Q1 到当前月所在季度（含）的所有阶段金额累计总和；若当前月不在数据范围内则累计全部 |
| 7.4  | 统计卡片 - 目标值           | 有数据                | 观察"目标"统计卡片        | 按月模式：从财年第一个月到当前自然月（含）的 target 累计总和；按季度模式：从 Q1 到当前月所在季度（含）的 target 累计总和；若 target 总和为 0 则分母默认为 1    |
| 7.5  | 统计卡片 - 达成率           | 有数据                | 观察"达成率"统计卡片      | 显示 = round(当前值 / 目标值 × 100)%；≥90% 显示绿色，<90% 显示红色                           |
| 7.6  | 健康状态标签                | 有数据                | 观察图表卡片右上角        | 当前值 ≥ 目标值×0.9 时显示"健康"（绿色），否则显示"低于目标"（红色）                         |
| 7.7  | 点击月份柱子                | 有数据，按月模式      | 点击某月（如 Mar）的柱子  | 健康度卡片高亮并高亮 Mar，其他月份柱透明度降为 0.3；下方展开商机列表，列表仅显示 createdYearMonth 对应 Mar 的商机 |
| 7.8  | 点击季度柱子                | 有数据，按季度模式    | 点击某季度（如 Q1）的柱子 | 健康度卡片高亮并高亮 Q1；下方列表及后续图表仅使用 Q1 对应财年月份的商机                                |
| 7.9  | 月份/季度筛选联动漏斗和停滞 | 已点击健康度某月/季度 | 观察漏斗图和停滞图        | 漏斗图按该月份/季度过滤；未选择漏斗阶段时，停滞图也按该月份/季度过滤                                   |
| 7.10 | 切换月份并清除下游条件      | 已完成“Mar→某阶段→某状态”三级钻取 | 点击 Jun 的柱子 | 月份更新为 Jun，原阶段和停滞状态被清除；漏斗按 Jun 展示全部阶段，停滞图按 Jun 展示全部阶段和状态       |
| 7.11 | 关闭商机列表                | 商机列表已展开        | 点击列表右上角 X 按钮     | 商机列表收起，整条钻取路径清空，健康度月份高亮、漏斗阶段高亮和停滞状态高亮全部取消                     |
| 7.12 | 业务图表逐级激活样式        | 已依次选择月份、阶段和状态 | 观察三个业务图表       | 健康度、漏斗、停滞卡片均保持选中高亮，不因选择下一级而降低透明度；仅回款图激活时业务图表降低视觉优先级 |
| 7.13 | 图例显示                    | 有阶段配置            | 观察图表底部图例          | 显示各阶段名称（来自 stages[].name）和对应颜色方块，以及 target 虚线图例                     |
| 7.14 | Tooltip                     | 有数据                | 鼠标悬停某月柱子          | 显示该月各阶段的金额明细                                                                     |
| 7.15 | 筛选条件标签                | 已选中组织和产品线    | 观察图表卡片顶部          | 显示当前年份标签、组织名称标签（可点 X 移除）、产品线标签（可点 X 移除）                     |
| 7.16 | 季度模式下统计卡片          | 按季度模式            | 观察统计卡片              | 当前值和目标值按季度聚合后的数据计算，逻辑与按月模式一致（累计到当前月所在季度）             |

## 八、销售漏斗图 (FunnelChart)

| 编号 | 用例名称                                          | 前置条件                                         | 操作步骤                                                           | 预期结果                                                                                                                                                                                                                                                                                                                                                                         |
| :--- | :------------------------------------------------ | :----------------------------------------------- | :----------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 8.1  | 漏斗条渲染                                        | 有商机数据                                       | 观察漏斗图                                                         | 按 opportunityStages 顺序从上到下显示各阶段，每个阶段显示为水平条形，左侧显示阶段名称和商机数量，条形内显示金额，右侧显示转化率标签                                                                                                                                                                                                                                              |
| 8.2  | 漏斗条宽度                                        | 有数据                                           | 观察各阶段条形宽度                                                 | 宽度按 count / maxCount 比例计算，count 最大的阶段占满宽度                                                                                                                                                                                                                                                                                                                       |

| 8.4  | 转化率健康标签                                    | 有数据                                           | 观察条形右侧转化率标签                                             | actualConversion ≥ targetConversion 时显示绿色背景 + 上升箭头图标，否则显示红色背景 + 下降箭头图标；同时显示 "actualConversion% / targetConversion%"                                                                                                                                                                                                                             |
| 8.5  | 统计卡片 - 总管线                                 | 有数据                                           | 观察"总管线"卡片                                                   | 显示所有阶段 value 之和，格式为货币                                                                                                                                                                                                                                                                                                                                              |
| 8.6  | 统计卡片 - 活跃商机                               | 有数据                                           | 观察"活跃商机"卡片                                                 | 显示所有阶段 count 之和                                                                                                                                                                                                                                                                                                                                                          |

## 十七、全局筛选对回款健康度和月回款合同的联动总结

| 筛选器 | 回款健康度影响 | 月回款合同影响 |
| :--- | :--- | :--- |
| 年份筛选 | ✅ 根据组织财年计算 plannedDate 查询范围，重新查询应收和关联合同 | ✅ 刷新后按新财年应收下钻 |
| 组织筛选 | ✅ 在前端按应收 `paymentOwner` 的 ID/email/uid 过滤 | ✅ 使用同一批已过滤应收；无负责人仅在“全部组织”时保留 |
| 产品线筛选 | ❌ 不影响回款数据 | ❌ 不影响回款数据 |
| 金额模式 | ❌ 不影响，固定使用应收 plannedAmount/actualAmount | ❌ 不影响，固定展示合同及应收金额 |
| 时间切换（月/季） | ✅ 按月显示 12 项或按财年季度聚合 4 项 | ✅ 季度标签展开为 3 个月后筛选应收 |
| 币种切换 | ✅ 应收金额按应收币种转换为目标币种 | ✅ 合同、应收金额按各自币种转换为目标币种 |

回款模块数据流：
```text
组织树 + 选中年份
  → computeFiscalRange(dateFrom, dateTo)
  → 查询 receivable-plan-form：plannedDate inRange，获取当前财年计划应收
  → 按 paymentOwner（ID/email/uid）应用组织筛选；未选组织时保留未分配负责人
  → 从筛选前的当前财年应收提取去重 parentDataId
  → 按合同 id 批量反查合同，作为合同表展示元数据
  → 回款健康度按筛选后应收计算 plannedDate/actualDate/滚动逾期
  → 点击月或季度后再次按应收计划筛选，并按 parentDataId 分组显示合同
```

## 十八、回款滚动与逾期逻辑

### 数据范围

本节仅针对 **plannedDate 位于当前财年范围内** 的应收计划。上一财年计划且仍未回款的应收目前不查询、不计入首月期初逾期，也不滚动到当前财年。

### 逾期判定规则

| 编号 | 用例名称 | 前置条件 | 操作步骤 | 预期结果 |
| :--- | :------- | :------- | :------- | :------- |
| 11.1 | 未到期应收计划 | 应收计划 plannedDate 在当前日期之后 | 观察该计划在图表和列表中的状态 | 归入 nativePlan（蓝色），状态为"正常"，不产生滚动逾期 |
| 11.2 | 即将到期判定 | plannedDate 距当前日期 ≤14 天，actualAmount=0 | 观察状态 | 状态为"即将到期"，不产生滚动逾期 |
| 11.3 | 已全额回款 | actualAmount >= plannedAmount | 观察状态和滚动 | 状态为"已完成"，不产生任何滚动逾期金额 |
| 11.4 | 逾期未回款 | 当前日期 > plannedDate，actualAmount=0，月底已过 | 观察图表 | shouldRoll=true，overdueAmount=plannedAmount，该金额从下一月到当前月（含）逐月显示在橙色柱中 |
| 11.5 | 逾期但同月回款 | plannedDate=6/1，actualDate=6/20（同月）| 观察 | 状态为"逾期"，但 shouldRoll=false，保留在原月统计中，不滚动至下月 |
| 11.6 | 逾期且跨月回款（部分） | plannedDate=6/4，actualDate=7/6，actualAmount < plannedAmount | 观察 | shouldRoll=true，overdueAmount = plannedAmount - actualAmount（未回款余额），滚动到7月 |
| 11.7 | 无 plannedDate | 应收计划 plannedDate 为空 | 观察 | 视为正常，不参与逾期判定和滚动计算 |

| 编号 | 用例名称 | 前置条件 | 操作步骤 | 预期结果 |

| 11.9 | 逐月展示滚动 | 5月逾期 5000，当前是7月 | 观察6月和7月的橙色柱 | 6月 rolledOverdue += 5000，7月 rolledOverdue += 5000（逐月累加，从源月下一月到当前月） |
